# Rate-Limited Multi-Tenant SaaS API
A multi-tenant backend API built with **Node.js**, **Express**, **Redis**, and **PostgreSQL**, featuring distributed atomic rate limiting, cryptographic API key authentication, and strict tenant data isolation.
---

## 🛠️ Tech Stack
- **Runtime & Framework**: Node.js, Express.js
- **In-Memory Store**: Redis (`ioredis`)
- **Database**: PostgreSQL (`pg`)
- **Containers**: Docker
